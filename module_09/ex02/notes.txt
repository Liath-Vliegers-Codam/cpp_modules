================================================================================
                    FORD-JOHNSON ALGORITHM OVERVIEW
================================================================================

The algorithm works in THREE main steps:

STEP 1: PAIR UP & COMPARE
  - Split numbers into pairs of neighbors
  - Compare within each pair, identify larger and smaller element
  - Handle odd element out (no pair)
  - Result: two containers → "big" elements and "small" elements
  
  Example with: 7, 3, 9, 2, 5
    Pairs:        (7,3) (9,2) (5)
    Big numbers:  7, 9, 5
    Small numbers: 3, 2

STEP 2: RECURSIVELY SORT BIG NUMBERS
  - Take the big elements and apply the same algorithm (Step 1-3)
  - Keep recursing until you have only 1 element
  - Base case: 1 element is already sorted
  
  Recursion on: 7, 9, 5
    Pairs:        (7,9) (5)
    Big numbers:  9, 7
    Small numbers: 5
    → Recurse on: 9, 7
      Pairs:        (9,7)
      Big numbers:  9
      Small numbers: 7
      → Now we have 1 big element = SORTED! (9 is smallest of the remaining)

STEP 3: INSERT SMALL NUMBERS WITH JACOBSTHAL ORDER
  - You now have sorted big numbers and unsorted small numbers
  - Use binary search to insert small numbers into sorted container
  - BUT: use Jacobsthal sequence to determine the ORDER of insertion
  - This minimizes total number of comparisons
  
  Starting with: Big [5, 7, 9] and Small [3, 2]
    Insert following order: 1 → 3 → 2 → 5 → ...
    After all insertions: [1, 3, 4, 6, 8]

================================================================================
                       JACOBSTHAL SEQUENCE EXPLAINED
================================================================================

WHAT IS IT?
  The Jacobsthal sequence is: 1, 1, 3, 5, 11, 21, 43, 85, 171, ...
  
  Formula: (2^(k+1) + (-1)^k) / 3  where k is the index (k = 0, 1, 2, 3, ...)
  
  These numbers (especially 3, 5, 11, 21, ...) are called BOUNDARY POINTS.

WHY USE IT?
  When inserting small elements into sorted big elements using binary search:
  - Each insertion takes log₂(n) comparisons worst-case
  - Comparisons grow as the container gets bigger
  - By inserting in Jacobsthal order, you insert the "hard" elements first
    (those requiring biggest position changes) when the container is small
  - Then you insert "easy" elements when container is bigger
  - This BALANCES total comparisons across all insertions

INSERTION PATTERN:
  Follow this zig-zag order to minimize comparisons:
  
  1 → 3 → 2 → 5 → 4 → 11 → 10 → 9 → 8 → 7 → 6 → 21 → 20 → ...
  
  Breaking it down:
    • Jump to boundary 1:  insert element at index 1
    • Jump to boundary 3:  insert element at index 3
    • Backfill: index 2    (between boundaries 1 and 3)
    • Jump to boundary 5:  insert element at index 5
    • Backfill: index 4    (between boundaries 3 and 5)
    • Jump to boundary 11: insert element at index 11
    • Backfill: indices 10, 9, 8, 7, 6 (between boundaries 5 and 11)
    • Jump to boundary 21: insert element at index 21
    • Backfill: indices 20, 19, 18, ... (between boundaries 11 and 21)

WHY THIS ORDER?
  - Boundaries represent "farthest jumps" in insertion position
  - Inserting at boundaries is most expensive (biggest search range needed)
  - Do this FIRST while the container is small = fewer comparisons
  - Backfill between boundaries when container is larger (more expensive)
  - Overall result: FEWER TOTAL COMPARISONS than any other insertion order

KEY INSIGHT:
  Binary insertion into a sorted list takes log₂(n) comparisons.
  By inserting at Jacobsthal boundaries first (when n is small), then backfilling,
  you ensure that expensive insertions happen early when costs are low.

================================================================================
                         KEY ALGORITHM DETAILS
================================================================================

RECURSION FLOW:
  1. Start with unsorted sequence
  2. Pair up elements (neighbors)
  3. Compare within each pair → separate into big/small
  4. Recursively sort the big elements (go back to step 2)
  5. When big elements are sorted, use Jacobsthal insertion to insert small ones
  6. Return sorted sequence

JACOBSTHAL INSERTION:
  - Boundaries mark "farthest jumps" in the sorted container
  - Insert at boundaries FIRST when container is still small
  - Backfill between boundaries when container is larger
  - This optimizes total comparisons needed across all insertions

RECURSION BASE CASE:
  - If container has ≤ 1 element, it's already sorted → return
